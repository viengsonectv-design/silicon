# SIRICON website

A responsive, multilingual company profile website for SIRICON Sole Company Limited. The site is built with plain HTML, CSS, and JavaScript, so it can be hosted as a static website.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Contents

- Lao, Thai, and English language switcher
- Company overview, service areas, selected projects, contact details, and booking form
- Booking form that prepares a WhatsApp message to **+856 20 2249 8777**; the visitor reviews and sends the message in WhatsApp
- Project photographs and company logo sourced from the supplied SIRICON company profile

The website does not store or submit booking details to a server.
